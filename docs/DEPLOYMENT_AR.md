# نشر الموقع

## Supabase
- Project URL من Settings > API.
- Anon/Publishable key من نفس الصفحة.
- لا تستخدم service_role في الموقع.

## Cloudflare Pages
1. أنشئ حساب Cloudflare.
2. Pages > Create application.
3. ارفع مجلد `public` أو اربطه بمستودع Git.
4. اسم المشروع المقترح: `alrayyan123`.
5. Cloudflare سيعطي رابط `pages.dev` إذا كان الاسم متاحًا.
6. افتح الرابط من الهاتف والكمبيوتر.

## مهم
`pages.dev` لا يمكن ضمان اسم محدد مسبقًا؛ يعتمد على توفر الاسم في Cloudflare.
